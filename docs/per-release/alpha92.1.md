# alpha92.1 — release notes

_Compared against `alpha92`._

> **Patch release.** `alpha92.1.7z` contains only the paks and files that changed since `alpha92` (12 files, as complete pak triplets). Install `alpha92` first, then extract `alpha92.1.7z` over it and accept the overwrites.

## Highlights

### A very minor asset patch

alpha92.1 fixes **two minor visual issues** and nothing else. It does not fix any
crashes, gameplay problems or other major issues; if alpha92 works for you, this
patch only changes how a few items look.

- **Draconis Family shield:** fixed a bad mip (a texture detail level that looked
  wrong at some distances).
- **Ancestral armor:** new icons for the Ancestral, Unfinished Ancestral and Worn
  Ancestral sets.

### Install

This archive holds **only the four updated Materials paks** (AncestralMaterials,
UnfinishedAncestralMaterials, WornAncestralMaterials, DraconisMaterials). It is not
a full install:

1. Install **alpha92** first (and its "UE4SS new" requirement).
2. Extract `alpha92.1.7z` over it, accepting the overwrites. MO2 users: install it
   as a separate mod that loads after alpha92.

No save changes, no ESP or SyncMap changes.
