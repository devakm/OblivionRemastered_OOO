# Toolchain reference

The scripts, inputs and rules behind the release tracker. For the step-by-step
procedure of cutting a release, see [`release-process.md`](release-process.md).
For the architecture and the reasons behind it, see [`v2-design.md`](v2-design.md).

## Scripts

| Script | Role |
|--------|------|
| `scripts/release.py` | **The release command.** End-to-end: check SyncMap drift → hash → parse ESPs → update co-files → write the release notes → commit + tag → build `.7z` → optionally push + `gh release create`. `--patch` builds a delta-only archive for a patch release (`alphaNN.M`); see *Patch releases* in [`release-process.md`](release-process.md). |
| `scripts/gather_live.py` | **Staging planner.** Dry-run by default: plans which live-install files to add or update in `release/` (the ship-list comes from the ItemClone and MapClone trackers). `--apply` copies; `--only GLOB` stages a subset. Safe to repeat. See *Staging a release over several sessions* in [`release-process.md`](release-process.md). |
| `scripts/sync_syncmap.py` | Generates the two SyncMap variants (default + Deluxe) from the OOO_SyncGen source INI through the 3-gate workflow (`diff-show` → `sync-content` → `apply-swap`). `release.py` only runs its read-only `diff-check` and aborts on drift. |
| `scripts/sync_pages.py` | Diff-only by default: shows what it would render for the OBR pages in the devnull Pages repo. `--apply` skips pages marked `DO-NOT-REGENERATE`, which is currently all of them, so the site is updated by hand. Never commits or pushes. |
| `scripts/publish_github.py` | Standalone `gh release create / upload` driver for publishing a single tag. Dry-run by default; `--for-real` to publish. |
| `scripts/fetch_binary.py` | Downloads a historical binary from a GitHub Release, using its `.md` co-file as the URL index. Caches the `.7z` at `work/_release_cache/<tag>.7z` and verifies the SHA-256. |
| `scripts/backfill_v2.py` | One-shot historical rebuild from the source release folders. Already run for the alpha lineage; rerun only to redo history. |
| `scripts/build_records.py` | Standalone ESP inventory writer (used by `release.py` / `backfill_v2.py`). |
| `scripts/diff_records.py` | Standalone ESP-inventory diff renderer; produces the ESP-changes sections of the release notes. |
| `scripts/mapclone_changes.py` | Summarizes MapClone per-cell map changes (REFR suppression, position overrides, static ghost suppression, exterior fixes) for the release notes. |
| `scripts/update_cofile.py` | Standalone per-binary `.md` co-file appender; can re-stamp a single row. |
| `scripts/tes4_parser.py` | Wrye Bash adapter: `parse_esp(path)` → loaded `ModFile`. |
| `scripts/_wrye_bootstrap.py` | Bootstraps Wrye Bash as a library (skips the desktop-app start-up). |

## Repo layout

| Path | Role |
|------|------|
| `release/` | Working tree of the latest release, mirroring the install layout. Text files and co-files are committed; binaries are gitignored but physically present at staging time. |
| `manifests/<tag>.json` | SHA-256 + size of every file (text + binary) per release. The integrity record. |
| `docs/per-release/<tag>.md` | Release notes generated by `release.py` (also the GitHub Release body). |
| `docs/release-highlights/<tag>.md` | Optional hand-written headline notes; `release.py` puts them at the top of the release notes. |
| `dist/` | **Gitignored.** Per-tag `.7z` archives, uploaded to GitHub Releases. |
| `work/` | **Gitignored.** Scratch, gather reports, the `fetch_binary` cache. |
| `program/` | Program dashboard: `py -3 -m program.build_dashboard` writes `program/dashboard.html` (gitignored). |

## What gets committed per release

| Pattern | Committed? | Notes |
|---------|------------|-------|
| `*.json`, `*.ini`, `*.lua`, `*.md`, `*.txt`, `*.html`, `*.css`, `*.py`, `*.cfg`, `*.xml`, `*.csv`, `*.yaml`, `*.yml`, `*.toml` | yes | Text source files in `release/` |
| `*.esp.records/**/*.json`, `*.esm.records/**/*.json` | yes | ESP inventory bundle |
| `*.<binary-ext>.md` | yes | Per-binary release tracking co-files |
| `*.esp`, `*.esm` | **no** | Replaced by `.records/` for diffing and `.md` for tracking |
| `*.pak`, `*.ucas`, `*.utoc` | no | IoStore binaries |
| `*.dll`, `*.exe` | no | Native binaries |
| `*.dds`, `*.tga`, `*.png`, `*.jpg`, `*.jpeg`, `*.webp` | no | Image binaries |
| `*.uasset`, `*.uexp`, `*.umap`, `*.bsa` | no | UE asset blobs |
| `manifests/<tag>.json` | yes | Full file-level integrity record |
| `docs/per-release/<tag>.md` | yes | Generated release notes |

`.md` co-files and `.records/` directories are left out of `dist/<tag>.7z`; they are
repo metadata, not release content. Any other `*.md` under `release/` is left out
of the archive as well.

## Rules

| Rule | Detail |
|------|--------|
| **Game install is read-only** | Tooling reads from the Oblivion Remastered install but never writes to it. |
| **Source release folders are read-only** | `X:\games\Oscuro\` is read only by `backfill_v2.py`. |
| **No publish without explicit approval** | `release.py --for-real`, `git push`, `gh release create` are run deliberately, never as a side effect. |
| **Dry-run by default** | Anything with external side effects defaults to dry-run. |
| **No Git LFS** | Binaries stay out of git; they are distributed as GitHub Release assets. |
| **One commit per release** | Subject = release name; `git log` is the release history. |
| **Tag every release** | Lightweight tag matching the release name; `gh release` finds the artifact by tag. |
| **Edit in place** | The repo is the source of truth for text and metadata; no wipe-and-refill. |
| **Stable formats** | Manifests: keys sorted, 2-space indent. Inventories: each `<TYPE>.json` sorted by FormID. Paths in JSON are relative POSIX. |
| **Merges** | Always a merge commit (`merge.ff = false`); no squash or rebase merges. |

## External dependencies

| Dep | Why | Install |
|-----|-----|---------|
| `chardet`, `wxPython`, `lz4`, `pyyaml` | Wrye Bash transitive deps (listed in `requirements.txt`) | `py -3 -m pip install -r requirements.txt` |
| Wrye Bash checkout | TES4 parsing (GPL v3, hence this repo's licence) | `git clone https://github.com/wrye-bash/wrye-bash X:\dev\wrye-bash` (dev branch); set `WRYE_BASH_MOPY` if elsewhere |
| 7-Zip | Packaging | `winget install 7zip.7zip` |
| `gh` CLI | GitHub Releases | `winget install GitHub.cli` |
